### 🛡️ 01. Mobile App Security Analyzer (SAST & Binary SBOM)
<p>
  <img src="https://img.shields.io/badge/Python_3-3776AB?style=flat-square&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/Zero_JVM-Pure_Python-10B981?style=flat-square" />
  <img src="https://img.shields.io/badge/OWASP_Mobile_Top_10_2024-E11D48?style=flat-square" />
  <img src="https://img.shields.io/badge/CycloneDX_1.5_SBOM-0284C7?style=flat-square" />
  <img src="https://img.shields.io/badge/Scan_Speed-3_to_6_Seconds-F59E0B?style=flat-square" />
</p>

A **production-grade, zero-dependency Static Application Security Testing (SAST)** and **Software Bill of Materials (SBOM)** suite for Android APKs. Unlike legacy heavy decompilers that require a complete Java runtime and 60+ seconds per scan, this engine parses compiled Android binaries directly at the byte level in **3 to 6 seconds**.

#### 🔬 Execution Pipeline Simulation:
```shell
$ python -m analyzer --target release.apk --output cyclonedx.json
[+] [0.42s] Ingestion & Decompression (Zip-Slip & Zip-Bomb bounds checking) ........ [SECURE]
[+] [1.15s] Binary AXML Manifest Deserializer (Permissions & Exported Intent audit) . [FLAGGED: 2 Exported Components]
[+] [2.80s] Dalvik DEX Bytecode Scanner & Cryptographic Insecurity Engine ........... [SCANNED: classes.dex]
[+] [3.45s] Native ELF Binary Inspection (C/C++ .so shared libraries) .............. [VALIDATED]
[+] [3.82s] CycloneDX 1.5 SBOM & OWASP MASVS v2.0 Audit Report Generated ............ [SUCCESS]
─────────────────────────────────────────────────────────────────────────────────────────────
✓ Result: Scanned in 3.82s | Mapped to OWASP M1-M10 (2024) | Ready for CI/CD DevSecOps
```

- ⚡ **Zero-JVM Architecture**: Pure-Python byte deserializer for `AndroidManifest.xml` (AXML) and `classes.dex`.
- 📊 **OWASP & Compliance**: Mapped directly to **OWASP Mobile Top 10 (2024)**, **OWASP MASVS v2.0**, and **CWE**.
- 📦 **Supply Chain Security**: Emits **CycloneDX 1.5 JSON SBOMs** complying with modern supply chain standards.

### 💼 02. JobFlow — AI-Powered Mobile Recruitment Platform
<p>

An intelligent, multi-sided mobile recruitment ecosystem connecting **Job Seekers**, **Enterprise Employers**, and **System Administrators** into a real-time reactive workflow.

#### 🏗️ Architecture Topology:
```
┌─────────────────────────┐           ┌──────────────────────────┐

│ (Search, Apply, Status) │           │ (Postings, Review, Hire) │

             │                                     │
             └──────────────┐       ┌──────────────┘
                            ▼       ▼
              ┌───────────────────────────────────┐
              │    Flutter Reactive Mobile UI     │
              └─────────────────┬─────────────────┘
```

- ⚡ **Realtime Cloud Infrastructure**: Instant notifications, reactive status transitions, and secure authentication.
