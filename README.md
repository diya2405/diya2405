### 🛡️ 01. Mobile App Security Analyzer (SAST & Binary SBOM)
*Zero-Dependency, Pure-Python Static Application Security Testing Engine for Android APKs*

<p align="left">
  <img src="https://img.shields.io/badge/Python_3-3776AB?style=flat-square&logo=python&logoColor=white" />
  <img src="https://img.shields.io/badge/Zero_JVM-Pure_Binary_Parsing-10B981?style=flat-square" />
  <img src="https://img.shields.io/badge/OWASP_Mobile_Top_10_(2024)-E11D48?style=flat-square" />
  <img src="https://img.shields.io/badge/CycloneDX_1.5_SBOM-0284C7?style=flat-square" />
  <img src="https://img.shields.io/badge/Speed-3_to_6_Seconds-F59E0B?style=flat-square" />
</p>

* **The Challenge**: Legacy mobile security analyzers (like MobSF) take 45–90+ seconds per scan and require heavyweight Java runtimes, complex decompilers, and extensive system overhead.
* **The Engineering Solution**: Built from the ground up as a pure-Python, zero-dependency analyzer. Directly deserializes compiled Android binary XML (`AXML`), Dalvik executables (`classes*.dex`), and native shared libraries (`.so` ELF32/64) at the byte level in **under 4 seconds**.
* **Key Innovations**:
  * ⚡ **7-Stage SAST Pipeline**: Ingestion bounds checking (anti-Zip-Slip), manifest auditing, DEX bytecode scanning, crypto audit, and automated vulnerability scoring.
  * 📋 **Compliance Mapping**: Strict adherence to **OWASP Mobile Top 10 (2024 Release)** and **OWASP MASVS v2.0**.
  * 📦 **Software Supply Chain Security**: Emits **CycloneDX 1.5 JSON SBOMs** conforming to U.S. Executive Order 14028.

### 💼 02. JobFlow — AI-Powered Mobile Recruitment Platform
*Complete Cross-Platform Recruitment Ecosystem connecting Job Seekers, Employers, and Admins*

<p align="left">
  <img src="https://img.shields.io/badge/Flutter_3.x-02569B?style=flat-square&logo=flutter&logoColor=white" />
  <img src="https://img.shields.io/badge/Dart-0175C2?style=flat-square&logo=dart&logoColor=white" />
  <img src="https://img.shields.io/badge/Firebase_Firestore-FFCA28?style=flat-square&logo=firebase&logoColor=black" />
  <img src="https://img.shields.io/badge/AI_Resume_Parsing-10A37F?style=flat-square" />
  <img src="https://img.shields.io/badge/Architecture-Tri_Portal-7C3AED?style=flat-square" />
</p>

* **The Challenge**: Traditional hiring apps suffer from disjointed candidate tracking, slow manual resume reviews, and fragmented communication between candidates and hiring managers.
* **The Engineering Solution**: Architected a unified, reactive mobile platform with dedicated role-based interfaces (Job Seeker, Company/HR, and System Administrator) powered by Firebase realtime data synchronization and a Python AI matching pipeline.
* **Key Innovations**:
  * 📱 **Unified Tri-Portal Client**: Role-based access control with seamless Flutter navigation and clean Material 3 UI design.
  * 🤖 **Intelligent Match Engine**: Automated resume text parsing, skill vector extraction, and candidate-job matching algorithms.
  * ⚡ **Reactive Cloud Mesh**: Real-time application status updates, instant notifications, and cloud document storage.
